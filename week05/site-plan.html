Harare Tech Connect - Project Site Plan

WDD 231: Web Frontend Development I

1. Site Name

Site Name: Harare Tech Connect

Reason for selection: A central networking and resource hub for tech professionals and companies in Harare.

2. Site Purpose

The site provides a collaborative digital hub for regional tech professionals by listing local tech companies, upcoming hackathons, and membership forms.

3. Scenarios

  • Where can I find contact details and office locations for software firms in Harare?
  • How do I register my startup or join the regional tech directory?

4. Color Scheme

Primary Color (#1b4332): Used for headers and primary branding elements.

Accent Color (#40916c): Used for buttons and interactive highlights.

5. Typography

Heading Font: Inter, sans-serif

Body Font: Roboto, sans-serif
